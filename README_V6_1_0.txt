RUNNING COMEBACK v6.1.0 — VISIBLE VERSION LABEL

1. Back up data using More > Export backup before updating.
2. Upload the files from this ZIP into the ROOT of your existing GitHub Pages repository, replacing same-named files. Keep connect.html and any other existing files.
3. Once GitHub Pages deploys, close/reopen the app or refresh. Look for Version 6.1.0 beneath the home heading and under More > About Running Comeback.
4. Updated service worker cache and network-first handling for same-origin app files to help new releases show up.
5. The existing v6 app logic (Strava sync, 5K baseline, diary, weight tracking) is unchanged. Data and private access keys are not included in this ZIP.
