Import Strava runs

Import a Strava activities.csv export or a JSON file containing Strava activity records. Only runs are added; existing diary entries and weight measurements are kept. Use this only as a fallback if live Strava sync is unavailable.

For Strava CSV: request your account data export on Strava's website, unzip it and select activities.csv. Strava export columns may vary. Back up your diary before importing.

Data & coaching

Your data stays on this device in browser storage. Export it regularly to avoid losing your history if browser data is cleared.

Important health note

This app is a training log, not a medical diagnosis. With a previously unassessed calf/Achilles injury, consider a sports physiotherapy assessment before returning to running. Stop for sharp or increasing pain, limping or a sudden pop. Seek urgent assessment for a suspected tendon rupture.
