Running Comeback v7.9.0 — Nutrition Planner (13 October 2026)

New Nutrition tab with 14-day vegan rotation, 21 recipes, UK metric ingredient lists and methods, user-controlled ratings, approved swaps and recipe archive. Weekly shopping lists, daily food logging and editable calorie/protein/carbohydrate/fat targets.

Protein target is a MINIMUM; calories, carbohydrates and fat are MAXIMUMS. No automatic Team RH sync and no automatic nutritional calculations: enter values from actual product labels or your food diary. No calorie target inferred from BMR.

Existing running, Strava, strength, weight, recovery and check-in code retained. Existing localStorage key unchanged. Nutrition records are included in JSON backup exports and restored on import. Device data remains local only.

INSTALL: Back up the current app first. Upload all files in this ZIP to the root of your GitHub Pages repository, preserving filenames. Do not upload an old zip over this release. Refresh/reopen the installed PWA after publishing.

Includes corrected ankle mobility and calf stretch illustrations.
